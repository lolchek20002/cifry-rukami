# GESTURE — Цифры в твоих руках

Веб-приложение на HTML, CSS, JavaScript и MediaPipe Hand Landmarker. Распознаёт до двух рук, считает пальцы от 0 до 10, рисует скелет и неоновое число на Canvas. Настройки: зеркало, точки, пять цветов. Видео не записывается и не отправляется на сервер.

## Запуск

Нужен Node.js 20.19+ (или 22.12+).

```sh
npm ci
npm run dev
```

Откройте `http://localhost:5173`, нажмите «Включить камеру» и разрешите доступ. Камера работает на localhost или HTTPS. Для загрузки MediaPipe WASM, модели и шрифта нужен интернет: cdn.jsdelivr.net, storage.googleapis.com, fonts.googleapis.com, fonts.gstatic.com. Видеокадры обрабатываются локально.

```sh
npm test
npm run build
npm run preview
```

Для production раздавайте `dist` по HTTPS. Dev-сервер не является production-сервером.

## Как пользоваться

Держите ладони в кадре при хорошем освещении. Покажите кулак для 0, раскрывайте пальцы для 1–5, используйте обе руки для 6–10. После изменения жеста число стабилизируется за 130 мс. Когда руки исчезают, число скрывается. FPS показывает частоту обработки моделью.

Алгоритм использует углы суставов и расстояния между 3D-точками, включая большой палец. При перекрытии пальцев, сильном повороте ребром или плохом освещении возможны ошибки. Цифра размещается рядом с руками, выше ладони, с плавным перемещением; положение головы отдельно не определяется.

Если камера недоступна, проверьте разрешения сайта, подключение устройства и не занята ли она другой программой. При ошибке загрузки модели проверьте интернет и повторите запуск. GPU используется по возможности, предусмотрен CPU fallback. Частота распознавания ограничена примерно 22 кадрами/с, разрешение камеры — предпочтительно 960×720.

Реальную камеру и точность распознавания следует проверить вручную на целевом устройстве. Автотесты проверяют сглаживание и синтетические положения пальцев.
